# Glossary

The words on this site, in plain English.

| Word                      | Means                                                                                                  |
| ------------------------- | ------------------------------------------------------------------------------------------------------ |
| Headless CMS              | An editor for your website's words and pictures that's separate from the website itself. Sanity is one |
| Canonical                 | A tag telling search engines which address is the real version of a page                               |
| Redirect                  | An address that sends visitors on to another address                                                   |
| Structured data (JSON-LD) | Hidden information that helps search engines understand a page, like prices and FAQs                   |
| Crawler                   | A program, like Google's, that reads websites to list them                                             |
| Webhook                   | An automatic message one system sends another when something happens                                   |
| Stega                     | Invisible characters Sanity adds so you can click text on a preview to edit it                         |
| Dataset                   | The database where a Sanity site's content lives                                                       |
