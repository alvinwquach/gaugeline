# What each finding means and the usual fix

One row per Gaugeline check, with the level it is reported at: "Fix this first", "Fix soon" or "Worth knowing".
Look up the `checkId` of a finding here. The finding's own `evidence` has the specifics for this site.

The table is generated by `pnpm gen:skill` from the check registry. Do not edit between the markers.
