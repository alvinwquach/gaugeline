# gaugeline

Check a website the way search engines and visitors see it, and get a plain-English list of what to
fix first. Gaugeline only reads: every request is a `GET` or a `HEAD`, five at a time, and it never
requests addresses on your own computer or network unless you pass `--allow-private`.

```bash
npx gaugeline example.com
```

Requires Node.js 18.17 or newer.

## Usage

```bash
npx gaugeline example.com              # check a page and print what to fix first
npx gaugeline example.com --ci         # exit 1 on a "Fix this first" finding
npx gaugeline example.com --json       # a versioned JSON result (schema 1) on stdout
npx gaugeline 127.0.0.1:3000 --allow-private   # a development server on your own computer
```

Each run loads the page without running JavaScript, reads robots.txt, the sitemap, llms.txt and
the feeds, and samples a fixed number of links (30), images (20), sitemap pages (25), feeds (3),
llms.txt links (10), app store links (5) and structured data addresses (12). The limits cannot be
raised: they are a promise to the site being checked.
