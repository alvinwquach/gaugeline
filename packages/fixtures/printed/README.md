# printed

`register.csv`: an invented printed register for The Copper Kettle (`sites/printed-links`), six
rows in four places, with a byte-order mark and a quoted comma in "flyers, spring 2026". Nothing
here is a real business.

- `/menu` is on the table tents and the spring flyer: one request, reported with both places.
- `/table-menu?utm_source=…&utm_medium=qr` lands on `/menu` without its tags (printed-tags-lost).
- `/spring-flyer` is 404 (printed-dead).
- `/events-2025` lands on the home page (printed-to-home).
- `/book` lands on `/reservations`, as expected.
