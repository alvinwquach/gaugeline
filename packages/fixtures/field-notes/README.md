# Invented review notes for the field-findings miner (AG-15)

Every name, venue and detail here is made up (rule 12). `golden/` is the notes the docs page runs;
`hostile/`, `quiet/` and the `leaky-*` folders are the known-bad and edge cases the tests read.
`deny-list.txt` is the example owner's list of names that must never reach a draft. The same text is in
`packages/core/src/field-findings/example.ts`, and a test keeps the two equal.
