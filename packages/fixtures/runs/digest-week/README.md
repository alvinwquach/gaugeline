`harbour-books.example`, one a day from Monday 2 to Sunday 8 November 2026 at 15:00 UTC, for the
weekly digest (X41). Nothing here is a real site.

- The canonical tag and the missing alt text are there all week: still open. The alt text count
  changes on Friday (3 of 12, then 4 of 13), and it is still the same finding.
- A broken "Order online" link appears on Wednesday: new this week. Its address carries a
  `?session=` query string, which the digest must never show.
- The missing share picture is there Monday and Tuesday and gone on Wednesday: fixed this week.
