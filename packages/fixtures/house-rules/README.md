# House-rules fixtures (AG-17)

Invented rules files for the house-rules compiler. `style-guide.md` is the passing one: five lines the grammar
understands and two it does not. `hostile.md` is the failing one: a rule that would become an unsafe pattern, a
rule that names an absolute path, a line that gives an order to an assistant, and one rule that is fine. No real
business, person, address or phone number: the phone mask uses zeros.
