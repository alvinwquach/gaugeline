# old-theme-shop

An invented neighbourhood shop (Corner Pantry) on an old theme, for the served-libraries check (E-12). Nothing
here is a real business or a real library file: each script is a few invented lines with the banner or version
line a build tool would leave.

- `/assets/js/jquery.min.js` carries a jQuery 1.12.4 banner: `library-with-advisory`, with advisories whose
  range includes it.
- `/assets/js/moment.min.js` (2.29.4) and `/assets/js/lodash.min.js` (4.17.21) carry current versions: nothing.
- `/assets/js/bootstrap.min.js` is a Bootstrap file whose banner was stripped: its name says Bootstrap and
  nothing says which version, so it is could-not-check.
- `/assets/js/theme.min.js` is minified with no library name or version: counted in one could-not-check line.
