# nav-before

An invented bakery, Rye and Ember (`ryeember.example`), before a menu restructure, for the
navigation checks (X24). Nothing here is a real business. Every page has the same header and footer:

- header: Menu (Breads, Pastries under it), Catering, Gift cards, About, Visit;
- footer: Privacy, Terms, Blog;
- a sitemap of all 11 pages.

Run it with `--since last` to save its menu, then `nav-after` on the same host.
