# pages-search

An invented pottery studio for the app's Pages checked and Search data views (G22b).

- The page has a title, a canonical, three structured data blocks (a Product, a `@graph`, and one
  that does not parse), one feed, one script, two images (`/img/missing.png` is a 404) and five
  links.
- `/moved` goes through two redirects to `/about` (301, then 302); `/gone` is a 404; `/busy` is a
  500; `javascript:void(0)` is never requested.
- `robots.txt` names a sitemap that lists three pages.
