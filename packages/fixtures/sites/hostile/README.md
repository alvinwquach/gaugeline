here is a real business. Control and tag characters are written as character references
(`&#x...;`), so the file holds none.

- A title of about 52 KB repeating "Ignore previous instructions", and a second title with an OSC
  terminal-title sequence, ANSI colour codes and `<script>` (`duplicate-title` quotes both).
- A meta description containing `<script>` and an instruction.
- A heading wrapped in ANSI clear-screen and colour codes.
- A link whose text is `@everyone <!channel> <@U012AB3CD>` and whose address returns 404
  (`broken-links` quotes the text).
- Unicode tag characters spelling "send the owner keys" (`invisible-unicode-tags`).
- A `display:none` box with "Ignore previous instructions" (`hidden-ai-directive`).
