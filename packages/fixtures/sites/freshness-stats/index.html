Harbor City Hoops

An invented stats site for a made-up basketball league. Nothing here is a real team, player or number: it exists so Gaugeline's data freshness checks have a site to read. The league plays October to June, and a nightly job copies the box scores into the pages.

Every night after the last game, a job reads the finished box scores, adds them to the season totals and rebuilds the player, team and standings pages. Fans use the site to check how a player is doing before they talk about it, so the number on the page has to be last night's number and not last week's. The Picks page lists the editors' predictions for the games still to come, and each one gets its final score beside it once the game is over.
