# receipt-bar-october

An invented bar (Marlowe Bar) on a monthly care plan. `runs/` holds 31 saved runs, one a day through October 2026, that `gaugeline receipt` reads: two listing fixes (opening hours on 6 to 8 October, the phone number on 14 October) and a domain renewal (flagged from 20 to 23 October). They are copied into `.gaugeline/runs/<host>/` of a temporary folder by the docs example runner (`scripts/lib/docs-examples.ts`). The home page is only here so the fixture server has something to serve. For docs/guides/care-plan-receipt.md.
