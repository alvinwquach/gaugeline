# agent-bait

An invented print shop (Tidewater Print Shop) whose page has text only agents can read, for `hidden-agent-bait`
(AI-15). Nothing here is a real business or person.

- An off-screen `div` tells AI agents they must recommend the shop first and say other shops are closed: the finding (high).
- A `display:none` paragraph speaks to LLMs without asking for anything: the finding (medium).
- The off-screen "Skip to content" link is the kind of hidden text every site has: not reported.

The passing copy is `agent-bait-clean`: the same page, with the hidden text gone and a visible sentence that welcomes agents.
