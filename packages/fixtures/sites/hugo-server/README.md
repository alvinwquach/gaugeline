# hugo-server

The invented bakery blog (see `hugo-like`) served by `hugo server --buildDrafts --buildFuture` that was
left running as the live site (FW-08): it loads `/livereload.js` (`static-dev-server-live`), shows a
draft badge on an indexable page (`static-draft-marker-live`) and is dated 2031-01-04
(`static-future-post-live`).
