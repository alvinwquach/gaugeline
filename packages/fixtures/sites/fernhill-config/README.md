# fernhill-config

An invented neighbourhood taproom (Fernhill Taproom) for the config, baseline and suppression docs
(docs/config.md, docs/options.md). It ships a `gaugeline.config.json` (one check blocks, one is off, one
finding is snoozed until 31 December 2026) and a `gaugeline.baseline.json` written when the agency
took the client on, so a run reports only what is new since then. Nothing here is a real business.
