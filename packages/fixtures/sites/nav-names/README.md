# nav-names

An invented physiotherapy clinic (Millrace Physio) for `nav-link-no-name` (NAV-03). Nothing here is a real business.

- The header has an envelope icon to `/contact` with no label, and a phone icon (`tel:`) whose svg is `aria-hidden`: two findings.
- The same header has a labelled icon (`aria-label="Book a visit"`): named, fine.
- The footer has an image link with `alt=""`: a third finding.
