# host-previews

An invented cafe, `fernlight-cafe.test`, whose sitemap lists a Netlify deploy preview of its menu
page, `deploy-preview-12--fernlight-demo-0000.netlify.app` (an invented name, mapped to the fixture
server and never requested live). The preview serves the same files, so it answers 200, sends no
noindex and its canonical is its own: `host-preview-named` and `host-preview-indexable`.
